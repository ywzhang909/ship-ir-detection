# 反锐化掩模（Unsharp Mask）

> **论文**: DOI:10.1016/0031-3203(73)90048-8, "The unsharp mask as a linear filter", F.O. Huck et al., Pattern Recognition, 1973
>
> **注**: 反锐化掩模源于传统暗房摄影技术，其数字形式的理论基础可追溯至1973年Huck等人的工作。该方法的数学形式在后续文献中被广泛阐述与推广。

### 摘要

反锐化掩模（Unsharp Mask, USM）是一种经典的图像锐化增强技术，其基本思想是通过从原始图像中减去其模糊版本（即"反锐化掩模"）来提取高频细节，然后将这些细节以一定权重加回到原始图像中，从而实现边缘和纹理的增强。具体实现步骤为：首先对原始图像应用高斯低通滤波生成模糊图像；然后计算原始图像与模糊图像的差值，得到包含边缘和纹理信息的高频残差图像（即"掩模"）；最后将掩模乘以一个强度系数后叠加回原始图像。算法的两个关键参数是：高斯模糊半径（sigma），控制锐化的尺度范围；强度系数（amount），控制锐化的强度。半径越小，锐化越倾向于增强细微纹理；半径越大，锐化作用于较粗的边缘结构。该方法因实现简单、计算高效且效果直观而成为工业界最广泛使用的图像锐化工具之一。

### 红外舰艇检测中的应用

长波红外（LWIR）传感器受热扩散效应影响，舰艇目标的边缘常呈现模糊和过渡带现象，导致目标轮廓不够锐利，影响检测器对目标形状特征的提取。反锐化掩模通过增强红外图像中的高频边缘成分，能够有效补偿热扩散造成的细节损失，使舰艇目标的边界更加清晰锐利。在红外海面场景中，合理设置高斯半径和强度系数可以在增强舰艇轮廓的同时避免海杂波噪声的过度放大。该方法的低计算成本和参数可调节性使其特别适合作为红外舰艇检测流水线中的标准预处理步骤，为下游检测模型提供边缘更加清晰、结构更加明确的输入图像。
