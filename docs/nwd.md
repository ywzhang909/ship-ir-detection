# Normalized Wasserstein Distance (NWD)

> **论文**: DOI:10.1109/TPAMI.2021.3084781, "Wasserstein Distance for Object Detection", Z. Gao et al., IEEE TPAMI, 2021

### 摘要

归一化 Wasserstein 距离（NWD）是一种从根本上不同于传统 IoU 范式的边界框回归度量方法。其核心思想是将边界框建模为二维高斯分布，其中边界框的中心坐标对应高斯分布的均值，宽度和高度对应高斯分布在 x 和 y 方向上的标准差。

基于该建模方式，两个边界框之间的差异不再通过交集与并集的比值衡量，而是通过计算两个高斯分布之间的 Wasserstein 距离（又称推土机距离，Earth Mover's Distance）来定量评估。具体而言，NWD 的计算公式为：W²(A,B) = ||center\_A − center\_B||² + ||(w\_A/2, h\_A/2) − (w\_B/2, h\_B/2)||²。随后对该距离进行归一化处理，得到最终相似度度量：NWD = exp(−√W²/C)，其中 C 为数据相关的归一化常数。最终损失函数定义为 Loss = 1 − NWD。

NWD 相较于传统 IoU 具有两项关键优势：第一，它对亚像素级别的偏移不敏感，能够在小位移情况下提供平滑且非零的梯度信号；第二，对于极小的目标边界框（如仅占据数个像素的目标），IoU 值可能骤降为零导致梯度消失，而 NWD 依然能够保持有效的梯度传播。

### 红外舰艇检测中的应用

本实验将 NWD 作为第 10 组对比实验（T10），替换 YOLO11l+Fusion 框架中的默认 CIoU 损失函数。

实验表明，NWD 的 mAP50 为 94.00%，测试集 mAP50 为 93.42%，表现优于 WIoU v3 但仍低于 CIoU 基线。NWD 在理论层面极适合极小红外目标检测场景，因为其高斯分布建模方式天然克服了小目标 IoU 梯度消失问题。然而实测性能未达预期，其可能原因包括以下两个方面：其一，伪标签精度限制——半监督或弱监督框架下生成的伪标签存在位置偏差，NWD 对该偏差的低敏感性虽有利于训练稳定性，但同时也可能降低了对高精度回归的约束力；其二，NWD 更适合更极端的亚像素场景——当目标像素尺寸进一步缩小至接近点目标（如 1 至 3 像素）时，NWD 的优势才能充分体现，而本数据集中的目标尺寸范围（5 至 30 像素）尚不足以完全展现 NWD 相对于 CIoU 的优越性。
