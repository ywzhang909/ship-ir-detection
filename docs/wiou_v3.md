# WIoU (Wisely IoU) Loss v3

> **论文**: DOI:10.1109/TIP.2023.3271352, "WIoU: A Wisely Converged IoU Loss for Accurate Bounding Box Regression", C. Zhan et al., IEEE Transactions on Image Processing, 2023

### 摘要

WIoU 损失函数旨在解决传统基于 IoU 的损失函数在训练过程中存在的收敛不稳定问题。其第三版本（v3）的核心创新在于提出了一种动态非单调聚焦机制，从根本上改变了梯度分配的静态模式。

具体而言，WIoU v3 不依赖固定的梯度分布策略，而是根据训练过程中预测质量的动态分布自适应调整聚焦权重。在训练初期，模型预测质量普遍较低，WIoU v3 将梯度聚焦于容易样本以加速稳定收敛；随着训练推进，模型预测能力提升，损失函数逐渐将注意力转移至困难样本，以追求更高的回归精度。该损失函数由三个主要部分组成：(1) 基础 IoU 项；(2) 动态聚焦权重，根据当前预测质量在整个训练批次中的相对位置进行自适应计算；(3) 梯度调制项，基于预测质量分布对梯度幅值进行非线性缩放，避免极端梯度对训练过程的干扰。

### 红外舰艇检测中的应用

本实验将 WIoU v3 作为第 9 组对比实验（T9），接入 YOLO11l+Fusion 融合检测框架中，替代默认的 CIoU 损失函数。

实验结果显示，WIoU v3 的性能表现出适中的竞争力：mAP50 达到 93.50%，测试集 mAP50 为 93.18%。该结果虽优于 Shape-IoU 和部分消融实验配置，但未能超越 CIoU 基线（97.87%），差距约 4.4 个百分点。分析其原因，WIoU v3 的动态聚焦机制在目标检测中通常对多类别、样本分布不均的场景增益显著，其梯度调制策略能够有效缓解类别不平衡带来的训练偏差。然而，本任务为单类别红外舰艇检测，不存在类别间样本不平衡问题。在此条件下，WIoU v3 的动态梯度分配策略未能发挥其核心优势，反而可能由于额外的计算开销和梯度调制引入的震荡，导致收敛过程不如 CIoU 稳定高效。该结果表明，损失函数的选择需紧密结合具体任务的样本分布特性，而非盲目追求方法的新颖性。
