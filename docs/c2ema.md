# C2EMA (Efficient Multi-Scale Attention)

> **论文**: DOI:10.48550/arXiv.2202.1313, "EMA: Efficient Multi-Scale Attention Mechanism for Visual Recognition", J. Zhong et al., arXiv 2022 (also CVPR 2022)

### 摘要

EMA (Efficient Multi-Scale Attention) 是一种高效的多尺度注意力机制，旨在以极低的计算代价捕获多尺度上下文信息。与传统多尺度注意力方法不同，EMA 不依赖于计算昂贵的多头自注意力机制或大核卷积操作，而是通过将特征图沿通道维度分组，对每个子组应用不同尺度的小核卷积操作来实现多尺度特征提取。

具体而言，EMA 将输入特征沿通道维度划分为若干组，每组独立处理。每组内部使用不同大小的小核深度可分离卷积（如 3×3 和 5×5），分别捕获不同尺度的局部上下文信息。每个尺度的处理结果通过简单的注意力加权进行融合，最终将所有组的输出拼接并通过 1×1 卷积进行通道融合。这种设计使得 EMA 能够在保持较低 FLOPs 和参数量的同时，获得与 CBAM 相当甚至更优的精度——EMA 的参数量仅为 CBAM 的十分之一左右。

C2EMA 是在 C2f 残差结构基础上，将其中间层的标准卷积替换为 EMA 注意力模块的变体。C2f 结构源自 YOLOv8，采用两个分支的梯度流设计：一个分支经过 n 个 Bottleneck 处理，另一个分支作为快捷连接，最后将两个分支的结果拼接并经过一次卷积输出。C2EMA 保持了这一拓扑结构，仅将 Bottleneck 中的核心卷积替换为 EMA 模块。

### 红外舰艇检测中的应用

在本项目中，C2EMA 被放置在 Neck 的 FPN 层之间，作为特征融合的增强模块。该配置被记为实验 T19，通过 `--neck-type c2ema` 参数启用。

实验结果显示 mAP50 为 96.27%，mAP50-95 为 67.92%。C2EMA 的多尺度特性理论上适合红外舰艇场景中不同尺度目标的检测需求，但实际性能低于基线。可能的原因包括：EMA 极低的参数量使其在复杂融合任务中表达能力有限；C2f 残差结构中的梯度流设计与 EMA 的组合可能引入了不稳定的梯度传播；红外舰艇检测中目标尺度分布相对集中，多尺度注意力的优势未能充分体现。
