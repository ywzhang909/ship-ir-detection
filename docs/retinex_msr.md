# 多尺度Retinex（Multi-Scale Retinex, MSR）

> **论文**: DOI:10.1109/34.561227, "A multi-scale retinex for bridging the gap between color images and the human observation of scenes", D.J. Jobson et al., IEEE Transactions on Image Processing, 1997

### 摘要

多尺度Retinex（MSR）基于Land的Retinex色彩恒常性理论，将图像分解为反射分量和照度分量。反射分量表征物体的固有表面属性（如纹理、边缘和细节），照度分量则代表场景中的光照变化信息。MSR的核心思想是在多个不同尺度的高斯滤波下分别执行单尺度Retinex（SSR）分解，然后将各个尺度的处理结果进行加权融合。这一多尺度策略能够同时保留大尺度场景的整体光照感知和小尺度局部细节的增强效果。数学上，MSR的输出为各尺度SSR结果的加权和，其中权重可根据应用需求调整。该方法在雾霾去除、低照度增强和非均匀光照校正等任务中表现出色，能够有效恢复图像中因光照不均而损失的结构信息。MSR在红外图像处理领域的引入为克服红外传感器动态范围局限和海面复杂光照环境提供了有效的理论工具。

### 红外舰艇检测中的应用

海面红外图像常受到海面眩光、太阳反射和大气散射等非均匀光照条件的影响，导致舰艇目标的部分区域被强光掩盖或淹没在阴影中。MSR通过将红外图像分解为照度和反射分量，能够有效分离海面眩光（照度成分）与舰艇目标的结构信息（反射成分）。多尺度策略使得算法既能补偿大范围的海面光照梯度变化，又能保持小尺度的舰艇边缘和纹理细节。特别地，在低对比度海况（如雾天或夜间）下，MSR能够在不引入明显伪影的前提下显著提升舰艇目标的可检测性，为基于深度学习的检测器（如YOLO系列）提供更清晰、更具判别力的输入特征。
