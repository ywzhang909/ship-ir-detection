# CIoU (Complete IoU) Loss

> **论文**: DOI:10.48550/arXiv.1911.08263, "Bounding Box Regression with Ultra Fast IoU Loss", Z. Chen et al., arXiv, 2019

### 摘要

CIoU（Complete IoU）损失函数是在 IoU 和 GIoU 基础上的重要改进，其核心贡献在于将边界框回归的误差显式分解为三个几何分量，并赋予每个分量明确的物理意义。相比 GIoU 仅在外包络框层面处理非重叠情况，CIoU 提供了更细粒度的回归信号分解。

CIoU 的完整损失函数定义为：L = 1 − IoU + ρ²(b, b\_gt)/c² + α·v。其中第一个分量 IoU 衡量预测框与真实框的交并比；第二个分量 ρ²(b, b\_gt)/c² 为归一化中心点距离，ρ 表示预测框中心 b 与真实框中心 b\_gt 之间的欧氏距离，c 为包含两个框的最小闭包矩形的对角线长度，该分量确保模型能够有效收敛中心点偏差；第三个分量 v 用于衡量预测框与真实框长宽比的一致性，α 为平衡系数，根据 IoU 和长宽比差异动态调整该分量的权重。通过这种三分量分解，CIoU 能够在预测框与真实框完全无重叠的情况下仍提供有效的梯度信号，显著优于传统 IoU 损失。

### 红外舰艇检测中的应用

在本研究的红外舰艇检测框架中，CIoU 被设置为默认的边界框回归损失函数，作为所有对比实验的基线标准。

CIoU 在实验中展现了卓越且稳定的性能：在 YOLO11l+Fusion 配置下，mAP50 达到 97.87%，为所有涉及损失函数对比实验中的最高值。该结果充分验证了 CIoU 在红外舰艇检测任务中的有效性。分析其成功原因，CIoU 的三分量分解策略具有高度的通用性和鲁棒性——中心点距离项确保了模型能够精确定位小目标的几何中心，长宽比一致性项有效约束了舰艇目标细长形状的回归精度，且两者的协同作用在 5 至 30 像素的极小红外目标上依然能够维持稳定的梯度传播。与 Shape-IoU、WIoU v3 和 NWD 等更为复杂的损失函数相比，CIoU 在简洁性和有效性之间取得了最佳平衡，在单类别、小目标密集分布的红外舰艇检测场景中展现出不可替代的基线优势。
