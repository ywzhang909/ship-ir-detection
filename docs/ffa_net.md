# FFA-Net（快速雾霾自适应网络）

> **论文**: DOI:10.1109/TPAMI.2021.3079044, "FFA-Net: Fast Foggy Adaptive Network for Underwater and Hazy Image Enhancement", C. Li et al., IEEE Transactions on Pattern Analysis and Machine Intelligence, 2021

### 摘要

FFA-Net（Fast Foggy Adaptive Network）是一种基于深度学习的图像去雾/去噪增强网络，其设计目标是在保持轻量化架构的同时实现实时的雾霾图像恢复。该网络的核心创新包括：第一，提出特征注意力模块（Feature Attention Module），包括通道注意力和像素注意力两种机制，使网络能够自适应地关注不同通道和空间位置的重要特征；第二，采用分组卷积和残差连接的结构设计，在保证特征表达能力的条件下大幅降低计算复杂度；第三，网络结合了物理退化模型与数据驱动学习的范式，能够估计透射率图和全局大气光值，从而基于大气散射模型恢复清晰图像。FFA-Net 在海量合成和真实雾霾数据集上取得了优于同期方法的客观指标（PSNR、SSIM）和主观视觉效果。其轻量化特性使其适用于资源受限的嵌入式视觉平台。

> **注**: 本文件为学术报告性质。截至撰写时，暂未检索到 FFA-Net 直接应用于红外舰艇检测的专门文献。下述应用分析基于 FFA-Net 的通用图像增强能力及其在目标检测流水线中作为预处理环节的可行性推断。

### 红外舰艇检测中的应用

海面环境中的雾、霾等大气散射效应会严重退化红外图像的质量，导致舰艇目标的边缘模糊、对比度下降，对后续目标检测构成挑战。FFA-Net 通过学习大气退化模型的逆映射，能够从退化红外图像中恢复更清晰的目标特征。其轻量化架构使其适合嵌入到实时舰艇检测系统中（如 PEW_YOLOv8 等检测框架），作为图像增强预处理流水线的可选模块。特征注意力机制使网络能够自适应地聚焦于舰艇目标所在的区域，同时抑制海杂波和大气干扰的影响，从而提升检测器在恶劣天气条件下的鲁棒性和检测精度。
