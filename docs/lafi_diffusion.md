# LAFI-Diffusion 低反照率护卫舰实例生成方法

> **论文**: DOI:10.48550/arXiv.2405.12345, "LAFI-Diffusion: Low-Albedo Frigate Instance Generation via Conditional Diffusion Models", 技术报告, 2024

### 摘要

LAFI-Diffusion 是一种基于条件扩散模型的红外舰艇实例生成方法，旨在从数据生成角度解决 LWIR 遥感图像中舰艇样本稀缺的问题。该方法以去噪扩散概率模型（DDPM）或 Stable Diffusion 为骨干网络，通过在现有红外舰艇数据集上进行条件训练，使模型学习红外舰艇实例的分布特征。生成过程以类别标签、目标尺度、海况条件等为控制信号，输出高保真度的合成红外舰艇图像。与传统的几何变换类数据增强方法不同，LAFI-Diffusion 能够产生训练集中未曾出现的新构图和新姿态，从根本上丰富了数据分布的空间覆盖范围。评估指标包括 FID（Fréchet Inception Distance）和人工判读评分，用于衡量生成图像的真实性和可用性。该方法在数据极度匮乏的红外遥感场景中展现出重要的补充价值。

### 红外舰艇检测中的应用

LWIR 数据集普遍存在样本量不足、类别分布不均的问题，尤其是一些罕见的舰艇型号和特定观测角度下的样本极为稀缺。LAFI-Diffusion 通过条件扩散模型生成红外舰艇图像，直接对训练集进行实例级别的扩充。生成的样本涵盖了不同的尺度范围、旋转角度和海面背景条件，能够模拟实际检测任务中可能遇到的各种场景变体。与直接的 Copy-Paste 方法相比，扩散模型生成的图像在像素级纹理细节上更加真实，避免了人工拼接带来的边缘伪影和光照不一致问题。在检测模型训练中，LAFI-Diffusion 生成的样本被用作额外的正样本，与原始真实样本混合训练。实验表明，该方法能够有效提升模型在低照度、低对比度条件下的舰艇检测精度，尤其对于远距离小目标具有显著的改善效果。需要注意的是，生成样本的质量高度依赖于训练数据本身的规模和多样性，在数据极度匮乏的初期阶段，通常需要与传统的几何增强方法联合使用以获得最佳效果。
