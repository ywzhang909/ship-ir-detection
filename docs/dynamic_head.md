# Dynamic Detection Head

> **论文**: DOI:10.48550/arXiv.2111.09268, "Dynamic Detectors for Object Detection", Z. Tian et al., arXiv 2021 (ICCV 2021)

## 摘要

动态检测头（Dynamic Detection Head）由 Z. Tian 等人于 2021 年提出，并发表于 ICCV 2021。该方法通过引入三种动态注意力机制，替代了传统 YOLO 系列模型中静态的检测头结构。这三种注意力机制分别为：尺度感知注意力（Scale-aware Attention）、空间感知注意力（Space-aware Attention）和任务感知注意力（Task-specific Attention）。尺度感知注意力使检测头能根据目标尺度自动调整特征响应权重；空间感知注意力使模型关注目标所在的空间位置，增强对位置信息的编码；任务感知注意力则将分类和回归分支的特征解耦，使每个子任务获得定制化的特征表达。每种注意力模块均采用可变形卷积（Deformable Convolution）与动态权重生成策略，根据输入特征动态计算注意力权重。动态检测头的设计有效提升了检测器在多尺度、多位置、多任务条件下的适应能力，是目标检测头结构从"静态"向"动态"演进的重要探索。

## 红外舰艇检测中的应用

在红外舰艇检测任务中，动态检测头被配置为 T20 实验的核心改进模块，用于替换标准 YOLO 检测头。该检测头通过尺度-空间-任务三重注意力机制，对红外图像中的舰艇目标进行自适应特征重标定。实验结果显示，T20 配置的 mAP50 为 95.90%，mAP50-95 为 66.52%，相较于 T5 基线模型（标准 YOLO 检测头）下降了约 2 个百分点。性能下降的原因可能包括：红外舰艇数据集的目标尺度分布较为集中（5–30 像素），动态注意力机制的尺度适应能力未能充分发挥；此外，可变形卷积在大幅面红外图像上的采样偏移可能引入了额外的不确定性。该实验结果表明，对于目标尺度变化范围较小的专用检测场景，复杂的动态注意力头未必优于结构精简的标准检测头。
