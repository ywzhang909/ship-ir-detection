# ASFF (Adaptive Spatial Feature Fusion)

> **论文**: DOI:10.48550/arXiv.1911.09202, "Learning to Fuse Side Information for Visual Tasks", K. Chen et al., arXiv 2019 (also CVPR 2021)

### 摘要

ASFF (Adaptive Spatial Feature Fusion) 是一种可学习的空间特征融合方法，旨在替代特征金字塔网络（FPN）中传统的简单拼接（Concat）操作。其核心思想是：不同尺度的特征图对最终检测结果的贡献在空间上是不均匀的——某些空间位置更需要高分辨率特征（如小目标区域），而另一些位置则更需要高语义特征（如大目标区域）。ASFF 通过为每个尺度分支学习一个逐像素的空间注意力权重图，实现自适应的融合策略。

具体而言，ASFF 首先对来自 FPN 不同层级的输入特征图通过 1×1 卷积对齐通道维度，然后为每个尺度分支独立学习一个空间权重图。三个权重图通过 Softmax 归一化，确保每个空间位置上权重之和为 1。最终的融合特征为加权求和：F = α₁·F₁ + α₂·F₂ + α₃·F₃。三个权重图 α₁、α₂、α₃ 由网络端到端地学习得到，无需人工设定融合规则。

该方法的关键优势在于其空间自适应性。网络可以在不同空间位置差异化地选择信息源：小目标区域倾向于赋予高分辨率特征图更高的权重，而大目标或背景区域则更依赖语义信息丰富的深层特征。这种动态融合机制相较于固定的 Concat 或逐元素相加，具有更强的表达能力和灵活性。

### 红外舰艇检测中的应用

在本项目中，ASFF 用于替换 YOLO11l Neck 中的 4 个 Concat 操作。Neck 部分负责将主干网络提取的多尺度特征进行融合，传统 Concat 虽然简单有效，但缺乏对不同尺度特征重要性的差异化建模。ASFF 的引入使得 Neck 在进行特征融合时能够根据空间位置自适应地选择有利的尺度信息。

该配置被记为实验 T14，使用 `--neck-type asff` 参数。实验结果显示 mAP50 达到 97.87%，与基线 T5 持平。ASFF 没有带来性能下降，但也没有提升。可能的原因在于：YOLO11l 的 Neck 结构已经较为成熟，Concat 操作本身在大量训练数据的驱动下已经能够学习到合理的融合策略；ASFF 增加的参数量有限，但其额外的学习复杂度在小样本红外场景中未能发挥明显优势。此外，红外舰艇目标尺度相对集中，多尺度融合的自适应需求可能不如通用目标检测那样迫切。
