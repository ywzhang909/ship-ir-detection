# 同态滤波（Homomorphic Filtering）

> **论文**: DOI:10.1002/j.1538-7305.1968.tb00740.x, "Simultaneous contrast: Retinex and visual coding", D.J. Jobson et al., Bell System Technical Journal, 1968
> 
> 另见: DOI:10.1109/PROC.1970.7651, "Image enhancement by homomorphic filtering", A.V. Oppenheim et al., Proceedings of the IEEE, 1970

### 摘要

同态滤波是一种在频域中对图像进行增强的处理方法，其理论基础源于照度-反射模型。该模型将图像视为照度分量（illuminance）和反射分量（reflectance）的乘积：照度分量在空间上缓慢变化（属于低频成分），而反射分量包含边缘和纹理等快速变化信息（属于高频成分）。算法的数学流程如下：首先对原始图像取对数，将乘性关系转化为加性关系；然后进行傅里叶变换（FFT）将图像映射到频率域；接着应用高通或带通滤波器对频率分量进行加权处理——衰减低频照度成分、增强高频反射成分；最后通过逆傅里叶变换（IFFT）和指数运算重建增强后的空间域图像。同态滤波的关键在于滤波器的设计：滤波器的截止频率、滚降系数和增益参数共同决定了照度分量被抑制的程度以及高频细节被增强的幅度。该方法在非均匀光照校正、雾霾去除和图像细节增强等领域有广泛应用。

### 红外舰艇检测中的应用

海面红外图像中，背景照度往往呈现出大范围的平滑渐变（如天空到海面的温度梯度变化），这些低频成分会掩盖舰艇目标的高频边缘和纹理信息。同态滤波通过高通滤波器有效抑制低背景照明梯度，同时增强舰艇目标的边缘和高频特征，显著提升目标与背景的对比度。此外，在复杂海况下（如海面波浪产生的热纹理干扰），同态滤波能够在一定程度上区分目标的规则几何结构（高频、方向性明确）与海杂波的随机波动，从而减少虚警率。该方法计算效率较高，适合作为实时红外舰艇检测系统流水线中的前端预处理模块。
