# CBAM (Convolutional Block Attention Module)

> **论文**: DOI:10.48550/arXiv.1807.06521, "CBAM: Convolutional Block Attention Module", S. Woo et al., ECCV 2018

### 摘要

CBAM (Convolutional Block Attention Module) 是一种轻量级且通用的注意力模块，通过顺序应用通道注意力和空间注意力两个维度来增强特征表达能力。其核心设计理念是：注意力机制应该同时在"什么通道是有意义的"和"什么空间位置是有意义的"两个维度上发挥作用。

通道注意力分支首先利用全局平均池化和全局最大池化分别聚合空间信息，生成两个不同的通道描述符。这两个描述符被送入一个共享的双层 MLP（参数共享以减少参数量），然后通过逐元素相加和 Sigmoid 激活生成通道权重。与 SE 仅使用平均池化不同，CBAM 同时使用平均池化和最大池化来捕获更丰富的通道统计信息——平均池化聚合全局上下文，最大池化捕获最显著的特征响应。

空间注意力分支利用通道维度的池化操作（平均池化和最大池化沿通道维度进行）生成两个二维的空间特征图，将其拼接后通过一个 7×7 卷积和 Sigmoid 激活生成空间权重图。该权重图对原始特征图进行空间位置的加权，使得网络能够关注到目标所在的区域。

通道注意力和空间注意力以顺序方式串联（通道先、空间后），形成完整的 CBAM 模块。该模块参数量极少，可以即插即用地集成到任何 CNN 架构中，具有极好的模型无关性。

### 红外舰艇检测中的应用

在本项目中，CBAM 主要在融合模块的架构搜索中作为候选注意力机制进行评估。在实验 T1 配置中（h=32, l=3, CBAM），CBAM 被集成到 SpatialFrequencyFusion 模块中作为通道-空间双重注意力组件。

此外，在实验 T15 中，CBAM 与 ASFF 和 FECA 联合使用，构成多组件融合方案。实验结果表明，CBAM 在这种组合中未能带来明显的增益。可能的原因在于：红外舰艇检测中的特征融合可能主要受益于通道维度的重标定，而空间注意力的额外贡献有限；海面背景中的舰艇目标具有相对明确的空间位置信息，空间注意力的建模能力在该场景中被一定程度地浪费了。CBAM 的两种池化策略在红外场景中也可能受到海杂波和噪声的影响，导致注意力图不够聚焦。
