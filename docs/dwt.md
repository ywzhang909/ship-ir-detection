# 离散小波变换（DWT）

> **论文**: DOI:10.1063/1.555921, "Wavelets", Ingrid Daubechies, Communications on Pure and Applied Mathematics, 1992

### 摘要

离散小波变换（Discrete Wavelet Transform, DWT）是一种时间和频率的局部化分析方法，通过将信号或图像分解为不同尺度和方向的子带分量来提取多分辨率特征。在二维图像处理中，DWT 首先对图像的行施加低通滤波器（h）和高通滤波器（g）进行下采样，再对列施加同样的滤波器组合，从而将图像分解为四个子带：LL 子带（行和列均经过低通滤波）包含图像的低频近似信息，对应背景和缓慢变化区域；LH 子带（行低通、列高通）捕获水平方向的边缘细节；HL 子带（行高通、列低通）捕获垂直方向的边缘细节；HH 子带（行和列均经过高通滤波）捕获对角线方向的高频纹理和噪声。通过递归地对 LL 子带进行再次分解，可获得多尺度（多层）的小波表示，其中每一层对应不同空间尺度下的图像特征。DWT 的核心优势在于其多分辨率分析能力：不同尺度的子带系数将图像中的不同特征按频率和方向分离，为后续的选择性增强或抑制提供了灵活的操作空间。Daubechies 小波族通过紧支撑正交小波基实现了高效且可逆的分解与重构。

### 红外舰艇检测中的应用

在红外海面舰艇检测任务中，DWT 的多尺度分解特性与红外图像中目标和背景的频谱差异高度契合。通过对红外图像进行多层小波分解：LL 子带主要包含大面积海面背景和缓慢的温度梯度分布，可直接进行抑制（置零或加权衰减）；HH 子带主要包含传感器热噪声和海面纹理细节，同样需要抑制；LH 和 HL 子带则捕获了舰艇目标在水平和垂直方向上的边缘结构信息，应当予以保留并增强。在子带处理完成后，通过逆小波变换重构图像即可获得背景和噪声被有效抑制、目标边缘得到增强的预处理结果。DWT 相比纯频域方法的优势在于其空间局部化能力：小波系数同时携带频率和位置信息，使得目标增强和噪声抑制可以在局部自适应进行，而不是全局统一处理。这一特性对处理包含非均匀海杂波和局部热源干扰的红外图像尤为有利。
