# P2 Small Object Detection Head

> **论文**: DOI:10.48550/arXiv.2004.10934, "YOLOv4: Optimal Speed and Accuracy of Object Detection", A. Bochkovskiy et al., arXiv 2020

## 摘要

P2 小目标检测头最早由 YOLOv4 提出，旨在增强模型对小尺寸目标的检测能力。标准 YOLO 系列模型采用特征金字塔结构，通常包含 P3、P4、P5 三个检测尺度，对应下采样倍率为 8、16 和 32 倍的特征图。P2 检测头在此基础上新增了一个步长为 4 的检测分支，即在原始图像分辨率 1/4 的特征图上执行检测。在此分辨率下，模型理论上可检测到小至 16×16 像素的目标。P2 头的特征来源为对 P3 特征图进行反卷积上采样后的浅层特征，通过额外的特征融合路径将其接入特征金字塔。这一设计显著提升了模型对微小目标的感知能力，但代价是引入了额外的计算量和显存开销。P2 头的引入本质上是特征金字塔结构向更浅层扩展，使得网络能够保留更多空间细节，这对于空间尺度极小、纹理信息匮乏的目标检测尤为重要。

## 红外舰艇检测中的应用

在红外舰艇检测场景中，目标通常只有 5–30 像素，标准的 P3–P5 检测头在 8 倍下采样的特征图上仅能覆盖约 64×64 像素的最小有效感受野，远大于小目标自身尺寸，导致目标特征被背景信息稀释。P2 检测头在 4 倍下采样（Stride-4）的特征图上进行检测，有效感受野约为 128×160 像素，理论上能够捕获更完整的舰艇目标细节。然而，P2 头的引入带来了严重的显存压力。在训练过程中，包含 P2 头的模型需要约 18–22 GB 的显存（batch 训练），这超过了本研究使用的 RTX 5080 Laptop 16 GB 显存容量上限。因此，尽管 P2 头在理论上对红外小目标检测具有显著优势，但因硬件资源限制，在实际部署中无法直接使用。这一限制提示在资源受限平台上需探索更高效的小目标检测特征融合策略。
