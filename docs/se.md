# SE (Squeeze-and-Excitation) Attention

> **论文**: DOI:10.48550/arXiv.1709.01507, "Squeeze-and-Excitation Networks", J. Hu et al., CVPR 2018

### 摘要

SE (Squeeze-and-Excitation) 注意力机制是最具影响力的通道注意力方法之一，通过显式地建模通道之间的相互依赖关系来重新校准通道维度的特征响应。其设计哲学是：卷积操作本质上是在局部感受野内融合空间和通道信息，但每个通道的全局重要性往往被忽略——某些通道可能包含对任务至关重要的语义信息，而另一些通道可能主要贡献于背景或噪声。

SE 模块由两个核心操作组成。Squeeze（压缩）操作通过全局平均池化将每个通道的二维特征图压缩为一个标量，生成通道描述符向量。这个向量捕获了每个通道的全局分布信息，可以看作是该通道的全局统计量。Excitation（激励）操作使用一个 Bottleneck 结构的 MLP（FC → ReLU → FC → Sigmoid）来学习通道间的非线性依赖关系。第一个全连接层将通道数压缩为 r 倍（缩减率 r 通常为 16），引入 Bottleneck 结构一方面减少了参数量，另一方面迫使网络学习通道间的紧凑表示。第二个全连接层将通道数恢复至原始维度，Sigmoid 激活将输出映射到 (0,1) 范围，作为每个通道的权重。

最终的输出通过逐通道乘法将学习到的权重应用到原始特征图上，实现对通道响应的重新标定（Feature Reweighting）。SE 模块参数量极少，可以无缝嵌入到各种现代网络架构中，在 ImageNet 分类任务中在仅增加少量计算量的前提下带来了显著的性能提升。

### 红外舰艇检测中的应用

在本项目中，SE 注意力被用作 SpatialFrequencyFusion 模块中的默认注意力机制。该融合模块同时处理空间域和频率域的特征，通过 SE 对融合后的特征进行通道级别的重标定，自适应地强调信息量丰富的通道并抑制冗余通道。

在多个实验配置中（Run 3、T2、T4、T5、T7），SE 均作为默认注意力组件在融合模块中发挥作用。特别地，T5 作为基线配置取得了 mAP50=97.87% 的最佳性能。SE 在红外舰艇检测中的有效性可以归因于：红外图像中舰艇目标和海面背景的通道响应模式具有显著差异，SE 的通道重标定机制能够有效地突出目标相关的通道响应；同时，SE 的结构简单、参数量低，在大规模训练中易于收敛，不会给整体训练带来额外的负担。
