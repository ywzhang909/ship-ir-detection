# 鲁棒主成分分析（RPCA）— 非精确增广拉格朗日乘子法（IALM）

> **论文**: DOI:10.5555/3104322.3104349, "Robust PCA via Inexact Augmented Lagrange Multiplier", Z. Liu et al., NIPS 2010
>
> 基础理论: DOI:10.5555/3104322.3104337, "Robust principal component analysis?", E.J. Candès et al., STOC 2009

### 摘要

鲁棒主成分分析（Robust PCA, RPCA）是一种高维数据降维与异常检测方法，旨在将观测矩阵 $M$ 分解为低秩分量 $L$ 和稀疏分量 $S$ 之和，即 $M = L + S$。其中低秩分量 $L$ 对应数据中的全局结构化信息，稀疏分量 $S$ 对应数据中的稀疏异常或噪声。该问题通过求解如下凸优化形式实现：最小化 $\|L\|_* + \lambda\|S\|_1$，约束条件为 $M = L + S$，其中 $\|\cdot\|_*$ 表示核范数（矩阵奇异值之和），$\|\cdot\|_1$ 表示 $\ell_1$ 范数，正则化参数 $\lambda$ 平衡两项的权重。Candès 等人从理论上证明了在低秩和稀疏分量满足一定不相干性（incoherence）条件时，RPCA 能够以高概率精确恢复 $L$ 和 $S$。非精确增广拉格朗日乘子法（Inexact Augmented Lagrange Multiplier, IALM）是求解 RPCA 问题的主流高效算法之一。IALM 通过在拉格朗日函数中引入增广项，并在每次迭代中对 $L$ 和 $S$ 交替优化（而非精确求解子问题），大幅降低了计算复杂度，同时保持了良好的收敛性能。相比 Exact ALM，IALM 在每次迭代中仅需一次 SVD 分解，使其能够处理中等规模的图像矩阵。

### 红外舰艇检测中的应用

在红外海面舰艇检测场景中，海面背景通常呈现高度的结构相关性——大面积海水区域在空间上平滑连续，温度分布具有空间低秩特性。舰艇目标相对于海面面积小而稀疏，在图像中表现为孤立的结构化异常。RPCA 模型天然适配这一场景：低秩分量 $L$ 捕获海面背景（包括波浪纹理、光照梯度和传感器非均匀性响应），稀疏分量 $S$ 则捕获舰艇目标、海面亮点和生物发光点等稀疏成分。通过 IALM 求解 RPCA，可在无需先验目标信息的条件下实现背景与目标的分离。分解后的稀疏分量 $S$ 可直接用于目标检测和分割，大幅简化后续处理流程。该方法的一个关键参数是 $\lambda$，通常取 $1 / \sqrt{\max(m, n)}$（其中 $m$, $n$ 为图像尺寸），该取值由 Candès 等人从理论推导得出，在实际红外海面场景中表现良好。RPCA 相比传统滤波方法的优势在于其数据驱动的分解机制：背景和目标的分离开非基于预设的频率或形态学假设，而是基于数据的低秩和稀疏先验，因此对复杂海况和多样化的目标形态具有更好的适应性。
