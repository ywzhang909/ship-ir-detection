# 视频识别流程与结果分析报告

> 对象：`dataset/` 下的两段真实红外（LOW-IR）海面视频
> 模型：`T5_yolo11l_fusion`（YOLO11l 骨干，单类 `ship`，论文 §6 最佳 large）
> 输入：**灰度归一化（BGR→GRAY→BGR）+ 训练域对齐预处理**（默认 `raw`）
> 推理：SAHI 切片推理 · 置信度阈值 0.25 · 逐帧处理（stride=1）
> 生成：`ship_detector/export_results.py` + `ship_detector/render_gui_screenshots.py`

---

## 1. 概述

本报告对两段实拍红外海面视频执行逐帧舰船检测，输出：带置信度框的**标注结果视频**、机器可读的 **JSON 报告**、人类可读的 **Markdown 报告**，以及**软件界面截图**与**分析图**。

| 视频 | 分辨率 | 时长 | 帧数 | 含目标帧 | 检出率 | 目标总数 | 平均置信度 | 最高置信度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `mmexport1790781116796.mp4` | 1280×576 | 23.5 s | 705 | **657** | **93.19 %** | 659 | 0.787 | 0.896 |
| `mmexport1790781113092.mp4` | 1280×576 | 40.1 s | 1204 | 62 | 5.15 % | 67 | 0.487 | 0.851 |

两段视频难度差异极大，这是本报告最重要的结论：视频 B 检出稳定且置信度高；视频 A 仅约 5 % 的帧检出目标。后者不是模型故障，而是**跨域（domain gap）**现象——详见 §5。

## 2. 识别流程（含本次优化）

```
MP4 视频 (1280×576 @30fps)
   │  cv2.VideoCapture 逐帧解码 (BGR)
   ▼
① 灰度归一化  BGR → GRAY → GRAY2BGR      ← 本次新增：对齐训练色彩空间
   │   仓库全部模型均为单波段红外训练域，参考脚本先 IMREAD_GRAYSCALE 再 GRAY2BGR
   ▼
② 训练域对齐预处理 (可选) raw / tophat / butterworth / dual / wavelet / rpca
   │   对应 detector.preprocess_for 的路由, 参数逐项对齐 (见 §3)
   ▼
③ SAHI 切片推理：512×512 窗口, overlap=0.2, NMS + IOS 匹配 0.5, conf=0.25
   ▼
DetectedShip 列表（归一化 bbox + 置信度）
   ├──────────────► ④ 渲染：框 + 置信度标签 "ship #id XX%" → 标注结果视频
   ▼
⑤ 统计汇总 ──► JSON 报告 + Markdown 报告
```

### 实现要点

- **几何不变性**。①② 都是逐像素映射，输出与输入同尺寸同通道数（已由单测断言）。因此**检测框坐标可以直接映射回原始画面**——框画在原图上，与仓库既有 `detector.predict_image` 的约定一致（"预测在预处理图上，绘制在原图上"）。
- **灰度归一化恒开**。与 `detector.read_image_bgr` 完全一致：无论输入是彩色还是准灰度，都先折叠到单波段，避免色彩通道污染下游的白平衡增益估计。
- **可切换的预处理**。`--preprocess` 暴露全部 6 种训练输入分布，默认 `raw`（仅灰度归一化，不做增强）。
- **颜色一致性**。检测框颜色取自 `config.SHIP_CLASS_COLORS`（该表按 RGB 使用），cv2 需要 BGR，导出时做了通道翻转，保证标注视频与 GUI 截图的框颜色完全一致。
- **确定性抽帧**。生成截图时用 `CAP_PROP_POS_FRAMES` 精确 seek，而非依赖 QTimer 播放——离屏环境下推理阻塞，播放时钟会漂移。

## 3. 预处理实验：色彩空间对齐是否有效？

### 3.1 关键发现：实拍视频本身已是中性灰度

对两段视频抽样测量通道间差异：

| 视频 | mean\|B−G\| | mean\|G−R\| | mean\|B−R\| |
| --- | --- | --- | --- |
| `...113092.mp4` | 0.65 | 0.60 | 0.15 |
| `...116796.mp4` | 0.63 | 0.59 | 0.14 |

三个通道的平均差异均 **< 1 个灰度级**，即画面本身已经是中性灰度。因此 `BGR→GRAY→BGR` 对这段素材几乎是一个**恒等变换**——这也是实测结果变化极小的原因。

> 结论：色彩空间对齐是**正确的**（保证与训练一致，并消除绿色十字丝/边框等彩色叠加的干扰），但对**这段**素材而言并不是性能瓶颈。

### 3.2 实测：对齐前后对比（全片逐帧，SAHI，conf=0.25）

| 指标 | 对齐前（原始 BGR） | 对齐后（灰度归一化） |
| --- | --- | --- |
| 视频A 含目标帧 | 66（5.48 %） | 62（5.15 %） |
| 视频A 目标总数 | 76 | 67 |
| 视频A 平均 / 最高置信度 | 0.482 / 0.835 | **0.487 / 0.851** |
| 视频B 含目标帧 | 657（93.19 %） | 657（93.19 %） |
| 视频B 目标总数 | 659 | 659 |
| 视频B 平均 / 最高置信度 | 0.779 / 0.896 | **0.787 / 0.896** |

**视频 B（可靠视频）覆盖率完全一致，平均置信度略升；视频 A 略有变化。** 净效果接近中性，与 §3.1 的推断一致。

### 3.3 六种训练输入分布横向对比（抽样 stride=6）

| 输入分布 | 视频A 检出率 | 视频A 置信度 | 视频B 检出率 | 视频B 置信度 |
| --- | --- | --- | --- | --- |
| `raw`（默认） | 5.5 % | 0.478 | 91.5 % | 0.787 |
| `tophat` | **19.4 %** | 0.425 | 79.7 % | 0.590 |
| `butterworth` | 8.5 % | **0.548** | **94.9 %** | 0.683 |
| `dual`（T5 名义训练域） | 7.5 % | 0.442 | 85.6 % | 0.685 |

三个要点：

1. **`dual` 反而最差**。它虽是 T5 名义上的训练输入分布，但在实拍 LOW-IR 素材上把视频 B 从 91.5 % 拉到 85.6 %、置信度从 0.787 降到 0.685——典型的跨域失配：该流水线的 AWB / top-hat / 带通滤波是按 NSLSR 合成域调的，在近黑海天场景下给出与训练分布不符的响应。
2. **`tophat` 的"高检出"经不起检验**。它把视频 A 检出率抬到 19.4 %，但逐帧目视核对发现新增检出多为**低置信度（约 33 %）、框偏小且只覆盖十字丝附近的局部**，而真正显眼的舰船轮廓并未被框住；同时它显著拖累视频 B。故不采纳。
3. **`butterworth` 数据最好但存在疑点**。它在视频 B 上把检出提到 94.9 %，但目标总数从 108 升到 136（该视频通常只有 1 艘船），提示存在**重复框 / 同船多框**，属于"数量上升、未必是真实召回提升"。

> **由于这段素材没有人工标注真值，无法计算 precision / recall，** 因此本报告只陈述可观测的检出数与置信度，不宣称任何"精度提升"。基于上述证据，默认选择**训练域忠诚且不引入不可验证增强**的 `raw`（仅灰度归一化）。

### 3.4 附带发现：T5 权重未包含融合模块

核查 checkpoint 参数：`T5_yolo11l_fusion_best.pt` 与原生 `yolo11l.pt` **均为 1015 个参数张量**，且首层为 `model.0.conv.weight (64,3,3,3)`——**不含任何融合模块参数**。训练侧 `fusion_module.make_fusion_trainer_class` 是把融合模块以 `model.model[0] = Sequential(fusion, conv)` 的形式在 `get_model()` 时插入的，但保存的权重里没有这部分。因此推理时实际运行的是 **3 通道 YOLO11l**。这也解释了为何为融合结构准备的 `dual` 三通道输入（[spatial, freq, orig]）在实测中并不占优。

## 5. 讨论：为什么视频 A 检出率只有约 5 %

![原图与 CLAHE 增强对比](figures/video/video_v4_contrast_analysis.png)

视频 A 的多数帧只有目标轮廓的一点点热信号，甚至整帧近黑；视频 B 的目标热信号完整、对比清晰。原因是**域差**，而非模型故障：

1. **成像条件差异**：模型在 NSLSR / 合成渲染域训练，实拍 LOW-IR 的噪声、增益、海杂波分布与之不同；
2. **目标尺度极小**：远距离舰船在 1280×576 中仅数像素高，有效纹理几乎为零；
3. **近黑帧本身无目标**：视频 A 大量帧画面近乎全黑，视觉上也不存在可分目标。

这与仓库 README 中「跨域图像可能检出偏少甚至为零，属正常域差现象，并非工具故障」一致。

## 8. 复现方法

```bash
export PATH="$HOME/.local/bin:$PATH"        # uv 不在默认 PATH
cd /home/ws/code/ship

# 1) 逐帧检测 -> 标注视频 + JSON/Markdown 报告
#    --preprocess 可选 raw/tophat/butterworth/dual/wavelet/rpca

    --sahi --conf 0.25 --stride 1 --preprocess raw

    --stats figures/video/data/report_mmexport1790781113092.json \

cd ../../ship_detector

    --preprocess raw
```

## 9. 数据完整性

对两段视频的导出结果逐项交叉校验（每段 13 项、合计 26 项断言全部通过）：

- 标注视频帧数 == 源视频帧数（1204 / 705），分辨率不变；
- 有目标帧上标注视频与原视频存在像素差异（确认框确实被烧录）；
- `summary` 的处理帧数、含目标帧数、目标总数、检出率、平均 / 最低 / 最高置信度，全部与 `per_frame` 明细逐项吻合；
- `run.source_frames` 与顶层 `source_frames` 一致；
- 预处理层的几何不变性由单测断言（`tests/test_preprocess.py`）。
