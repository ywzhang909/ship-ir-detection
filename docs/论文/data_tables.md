# 论文数据表（data_tables.md）—— 全论文唯一数字真相库

> **本文件是整篇论文的唯一数字来源（canonical truth store）。** 所有数字均逐字转写自权威源文件，每个单元格标注来源。论文正文与图表生成 agent 只能从本文件取数，禁止出现本文件之外的任何数字。
>
> **权威源文件**：
> - `实验记录.md`（简称「实验记录」，章节号如 §1.1、§3.1、§4.6 等）
> - `yolo-training/test_set_results.json`（简称「test_set_results.json」，9 个实验测试集指标）
> - `yolo-training/results/standard_eval.json`（简称「standard_eval.json」，11 个实验标准推理指标）
> - `yolo-training/results/sahi_eval.json`（简称「sahi_eval.json」，10 个模型 SAHI 指标）
> - `yolo-training/docs/training_record.md`（简称「training_record.md」）
> - 记事本 `/tmp/ulw-20260920-125925.GVfOgB.md`（简称「记事本」，交叉校验用）
>
> **转写规则**：禁止推算/四舍五入/发明/合并数字；对已取消（❌）/未训练（🔧）方法不编造指标；状态列严格区分 ✅（实测）/ 🔧（已实现未训练）/ ❌（已取消）。凡非源文件直接给出的数字（如个别验证-测试差距），一律标注「计算值」并给出算式。
