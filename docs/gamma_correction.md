# 自适应伽马校正（Adaptive Gamma Correction）

> **论文**: DOI:10.1016/j.image.2015.10.009, "Image enhancement via adaptive gamma correction", J. Wang et al., Signal Processing: Image Communication, 2016

### 摘要

传统伽马校正采用固定的非线性幂律变换对像素灰度进行映射，公式为 $I_{\text{out}} = I_{\text{in}}^\gamma$。当 $\gamma < 1$ 时，低灰度区域被拉伸，暗部细节得以增强；当 $\gamma > 1$ 时，高灰度区域被压缩，亮部细节得到改善。传统方法的局限在于参数 $\gamma$ 需要人工调节，且无法适应图像内容的变化。自适应伽马校正（Adaptive Gamma Correction, AGC）通过对图像全局或局部统计信息（如均值、方差、直方图分布等）的分析，自动估计最优的伽马值。例如，基于图像平均灰度的AGC将 $\gamma$ 设为关于均值的函数：图像偏暗时选取较小的 $\gamma$ 拉伸暗区，图像偏亮时选取较大的 $\gamma$ 压缩亮区。更先进的AGC方法结合直方图熵最大化或对比度优化准则，在保持图像自然感的同时最大化信息量。AGC在低光照图像增强、水下图像校正和医学图像对比度调整等领域展现出良好的适用性。

### 红外舰艇检测中的应用

海面红外图像的灰度分布受大气衰减、探测距离、传感器灵敏度和天气条件等多种因素影响，不同场景下图像的亮度范围和直方图分布差异显著。自适应伽马校正能够根据每帧红外图像的统计特性自动调整伽马参数，补偿因大气传输损耗和探测器非均匀响应导致的亮度偏移，使舰艇目标与海面背景的对比度在最佳动态范围内得到展现。在远距离或雾霾天气条件下，红外图像灰度往往整体偏低且集中，AGC通过自适应拉伸低灰度区间可以有效增强微弱舰艇目标的可辨识度，同时避免过亮海面区域的信息饱和。该方法计算开销极低，适合作为实时舰艇检测系统中的自适应预处理环节。
