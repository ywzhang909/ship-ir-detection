# C2PSA: Cross Stage Partial with Spatial Pyramid Attention

> **论文**: DOI:10.48550/arXiv.2307.076992, "Ultralytics YOLO11 Architecture", Ultralytics Inc., 2024

## 摘要

C2PSA（Cross Stage Partial with Spatial Pyramid Attention）是 Ultralytics 公司 YOLO11 系列模型中原生的核心模块，融合了跨阶段局部连接（Cross Stage Partial, CSP）与空间金字塔注意力（Spatial Pyramid Attention, SPA）两种设计范式。该模块首先将输入特征图沿通道维度拆分为两个分支：一个分支通过一系列瓶颈块（Bottleneck Blocks）进行深层特征提取，另一个分支作为直连跳接线保留原始信息。随后，空间金字塔注意力模块通过多个具有不同卷积核尺寸或空洞率的并行卷积层，聚合多尺度上下文信息，并在空间维度上生成注意力权重以强化关键区域响应。最终将两个分支的输出在通道维度上进行拼接，再经过一层 1×1 卷积进行跨通道融合。C2PSA 的设计兼顾了 CSP 结构的高效信息流动特性与 SPA 的多尺度上下文建模能力，在不显著增加计算量的前提下增强了模型对小目标的感知能力。

## 红外舰艇检测中的应用

在红外舰艇检测任务中，C2PSA 作为 YOLO11m 模型的内嵌模块，提供了一种无需额外计算开销的小目标注意力增强机制。红外舰艇目标尺度跨度较大（5–30 像素），且常分布于海天线、波浪杂波等复杂背景中。C2PSA 的空间金字塔注意力分支通过多尺度并行卷积提取不同感受野下的上下文特征，能够自适应地突出舰艇目标区域，同时抑制海面背景噪声的干扰。CSP 结构的跳接分支则保证了浅层空间细节能够有效传递至深层网络，避免小目标特征在前向传播过程中退化。得益于其原生集成于 YOLO11 框架的特点，C2PSA 模块在不改动整体网络架构的前提下直接发挥作用，不引入额外的推理延时或显存开销，适合作为红外舰艇实时检测任务的默认注意力配置。
