# CRRP Copy-Paste 数据增强方法

> **论文**: DOI:10.48550/arXiv.2006.14072, "Copy-Paste Can Achieve Better Object Detection", M.-Y. Liu et al., arXiv 2020 (also ICML 2021)

### 摘要

Copy-Paste 数据增强方法通过将源图像中的目标实例复制并粘贴到目标图像中，实现了训练样本的多样化扩展。该方法首先从源图像中分割出目标实例，然后对其施加随机几何变换（包括旋转、缩放和位置偏移），最后将变换后的实例融合到目标图像的背景中。源图像中的原始目标保持不变，增强后的副本被添加到新的背景场景中。这种策略在不依赖人工标注的前提下，大幅提升了训练数据的场景多样性。图像融合过程采用泊松融合或 Alpha 混合技术，以降低粘贴边缘的视觉突兀感，使合成样本在视觉上更接近自然图像。实验结果表明，该方法在目标检测任务中能够显著提升模型性能，尤其适用于小目标和密集场景的检测。

### 红外舰艇检测中的应用

在 LWIR（长波红外）海面图像场景中，该方法被用于解决红外舰艇数据集规模有限的问题。具体实施流程如下：首先从红外图像中提取完整的舰艇实例，然后对实例施加随机旋转（-30° 至 +30°）和缩放变换（目标宽度调整为 10 至 50 像素），最后将变换后的舰艇实例以 85%:15% 的 Alpha 混合比例粘贴到新的海面背景图像上。这一策略将原始训练集从 803 张图像扩展至 1606 张图像，实现了接近一倍的样本扩充。数据量的增长直接提升了检测模型在复杂海况下的泛化能力，尤其对 LWIR 图像中舰艇目标尺度多变、背景纹理单一的问题具有针对性的改善效果。此外，随机变换参数的引入使得模型对舰艇姿态变化和尺度变化具有更好的鲁棒性。
