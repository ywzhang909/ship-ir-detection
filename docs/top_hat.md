# Top-hat / Bottom-hat 形态学滤波

> **论文**: DOI:10.1016/0031-3203(87)90010-5, "Morphological image analysis: applications", P. Soille, Pattern Recognition, 1987

### 摘要

Top-hat 变换是一种基于数学形态学的图像处理算子，通过从原始图像中减去开运算（先腐蚀后膨胀）的结果来提取暗背景上的明亮小特征。与之对称的 Bottom-hat 变换则通过原始图像减去闭运算（先膨胀后腐蚀）的结果来提取亮背景上的暗小特征。两种运算均使用结构元素（structuring element）作为探针，在图像中执行形态学操作。开运算能够移除小于结构元素尺寸的明亮细节，保留大尺度背景；闭运算则填补小于结构元素尺寸的暗细节。将原始图像与开运算结果相减即可获得 Top-hat 图像，其中的亮像素对应被去除的明亮小目标；将闭运算结果与原始图像相减则获得 Bottom-hat 图像，其中的亮像素对应被去除的暗小目标。Top-hat 变换的一个重要性质是其对光照梯度和背景不均匀性具有天然的鲁棒性：由于形态学开运算能够较好地估计背景分布，相减操作能够有效消除大尺度背景变化，仅保留局部对比度显著的细节特征。该方法无需参数化模型假设，计算效率高，适用于实时处理场景。

### 红外舰艇检测中的应用

在红外海面舰艇检测任务中，长波红外（LWIR）图像通常包含大面积的海面背景梯度，这些背景变化来源于海面温度分布不均匀、大气传输效应以及传感器非均匀性响应。Top-hat 变换凭借其形态学背景估计能力，能够有效消除这些大尺度背景变化，同时保留舰艇目标的小尺寸明亮特征。具体而言，选择适当尺寸的结构元素（通常略大于目标舰艇的预期像素尺寸），通过开运算估计海面背景分布，再通过减法操作提取候选目标区域。实际应用中，Top-hat 输出通常作为预处理步骤，后续接入阈值分割、特征提取或分类器以实现最终检测。该方法对海杂波中的小目标检测尤为有效，计算开销低，适合嵌入式和实时系统部署。
